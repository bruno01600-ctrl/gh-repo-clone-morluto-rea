# Enzo, pirate de la différence — site web

Site d'une seule page, sans dépendance ni compilation : `index.html`.

- **Voir le site** : ouvrir `index.html` dans un navigateur.
- **Ajouter / modifier les liens** (comme sur Linktree) : éditer le tableau `LIENS`
  en bas du fichier (titre, sous-titre, URL, icône, `primary: true` pour le bouton en or).
- **Mettre en ligne** : déposer `index.html` sur n'importe quel hébergeur statique
  (GitHub Pages, Netlify, OVH…).

Les liens Facebook / Instagram / cagnotte de la page Linktree sont à compléter :
la page Linktree n'a pas pu être lue lors de la création du site.
